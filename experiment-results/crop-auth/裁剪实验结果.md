# PhotoProof 裁剪实验结果

2026 年 10 月 13 日

在原仓库基础上新增了裁剪验证代码，使用提供的 `1.JPG` 完成了“原图签名 → 裁剪 → 生成证明 → 验证裁剪图”的流程。原图为 1440×810 像素，本次允许保留中间 720×810 像素，未缩小图片。

关键改动是：证明中检查裁剪图是否来自原图的指定区域；验证时从收到的图片重新计算数据，不能只检查证明本身。

| 测试 | 结果 |
| --- | --- |
| 按指定范围裁剪 | 通过 |
| 裁剪后改动一个像素 | 拒绝 |
| 裁剪后添加红色方块 | 拒绝 |
| 换成同尺寸的其他裁剪区域 | 拒绝 |
| 用原图代替裁剪图 | 拒绝 |
| 为改动像素的图重新生成证明 | 无法生成，约束检查失败 |

合法裁剪图和修改一个像素后的图片，还分别用独立进程读取已保存的证明进行验证，结果仍为通过和拒绝。

本次生成证明约 **1.79 秒**，读取图片并完成验证约 **27 毫秒**，证明文件 **128 字节**。电路编译和密钥生成另耗时约 **14.18 秒**；证明文件大小不包含证书和验证密钥。这是一次运行的结果。

目前已实现的是**事先指定范围的裁剪验证**。图片按 90×90 像素分块，裁剪边界需要与分块对齐，结果保存为 PNG。签名由本次实验生成的密钥完成，不代表原始拍摄者。旋转、缩放和多轮编辑尚未实现。
